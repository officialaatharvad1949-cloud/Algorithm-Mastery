In this problem , we have two functions 
1. Serialiaztion () -> converting binary tree into a string;
2. Deserialization () -> converting back the string into a binary tree.

   For the first function , we have to simply use the level order Traversal to convert the binary tree into a string level by level;

   for the second function , we gotta use the same level order logic here but for the string to convert it into a binary tree .
